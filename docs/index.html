Native macOS image resizing

Resize images without breaking your flow.

Tesviye turns repetitive image resizing into one focused step. Work with a single image or a full batch, choose the output you need, and keep everything on your Mac.

View version 1.0.0 View source
  • macOS 14+ Native SwiftUI app
  • 3 formats JPEG, PNG, WebP
  • On-device No image uploads

Focused by design

Everything you need. Nothing to manage.

Tesviye keeps batch resizing practical without turning it into a full image editor.

Batch processing

Select multiple images, review the list once, and process the entire set in a single run.

Finder Quick Action

Start directly from selected files in Finder and receive them in one Tesviye window.

Useful presets

Choose common HD, square, and social sizes or enter precise pixel dimensions.

Safe output

Keep originals, choose another folder, and avoid collisions with automatic numbered filenames.

Remembered settings

Your last size, format, quality mode, theme, suffix, and output location return on launch.

Light, dark, or system

Use the appearance that fits your desktop. The selected mode is saved automatically.

Three-step workflow

Select. Configure. Resize.

No projects, libraries, accounts, or upload queues between you and the output.

  1. 01

    Select images

    Choose files inside Tesviye or launch it from Finder with the selected images already loaded.

  2. 02

    Choose the output

    Set dimensions, aspect ratio behavior, format, quality mode, suffix, and destination.

  3. 03

    Review the result

    Track batch progress, see individual outcomes, and clear the entire selection in one action.

Output control

The right format for the next step.

Keep the original format or convert while resizing. Automatic quality is the default; manual control is one click away.

JPEG Photos and the web

Adjustable quality with a selectable background color for transparent source images.

PNG Transparency and detail

Lossless output for graphics, interface assets, and images that must retain transparency.

WebP Modern delivery

Compact modern output powered by libwebp, with automatic or manual quality selection.

Native by principle

A small utility that behaves like a Mac app.

Tesviye is built for a focused desktop task, using platform conventions and local processing.

  • Private

    Image processing happens locally. Tesviye has no account system, analytics SDK, or upload service.

  • Efficient

    The app performs work when requested, saves preferences on exit, and does not remain running in the background.

  • Open

    The source is available under GPL-2.0, with libwebp acknowledged in the repository’s third-party notices.
